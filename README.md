# 班級量化統計與學生剖析系統 (Classroom Quantitative Analytics Hub)

> 專為**國中數學科任教師 兼 班級導師**打造的高效、私密、客觀量化統計與教學決策戰情室。

---

## 🌟 核心特色

1. **智慧課表排程與自動班級切換**
   - 設定週一至週五 1~8 節與早自習課表。
   - 根據真實時間每分鐘自動載入當前上課班級。
   - 支援 1 鍵快速手動覆寫（調課/代課模式），不干擾固定排程。

2. **導師班 vs 科任班 雙模式**
   - **導師班（本班）**：涵蓋生活常規（遲到、聯絡簿、打掃、同儕衝突）、心理情緒、出缺席與學業。
   - **科任班（任教班）**：聚焦數學課堂參與、解題亮點、小考/作業、專注度。

3. **統計學 $\times$ 國中教育剖析模組**
   - **EWMA 時序趨勢線**：平滑短期雜訊，精準反映學生近期真實向上或下滑走勢。
   - **$2\sigma$ 斷崖式下滑警訊**：自動偵測個人指標急墜的學生，提醒導師及時晤談介入。
   - **五數綜合箱形圖 (Box Plot)**：即時分析全班中位數、四分位距 ($IQR$) 與雙峰離散程度。
   - **因材施教四象限分群**：自動劃分「拔尖進階組」、「潛力未發揮組」、「努力待輔導組」、「高危機關懷組」。

4. **100% 本地隱私與零依賴**
   - 免安裝任何伺服器或環境，雙擊 `index.html` 即可在 Chrome / Edge / iPad / 電子白板上秒開使用。
   - 資料 100% 存於本機瀏覽器（LocalStorage / IndexedDB），個資無外洩風險。

5. **AI 友善標準資料格式 (JSON / CSV)**
   - 內建格式規範說明與「複製 AI 轉換指令」，能讓 ChatGPT / Claude / Gemini 將各校外部成績與名冊一鍵轉為標準格式匯入。

---

## 🚀 快速開始

1. 使用任一瀏覽器直接開啟 `index.html` 即可開始使用。
2. 系統已預載示範班級（801 導師班、803 數學班、805 數學班）與豐富的模擬數據，方便您立即體驗所有統計圖表。
3. 您可以隨時在「資料中心」點擊「清除示範資料」建立您自己的專屬班級。

## 📄 AI 匯入格式規範 (AI Schema Guide)

### 1. 小考/段考成績匯入 (JSON)
```json
{
  "class_id": "801",
  "assessment_name": "第三章一元二次方程式小考",
  "date": "2026-09-15",
  "max_score": 100,
  "records": [
    { "seat_no": 1, "score": 85, "note": "計算題粗心" },
    { "seat_no": 2, "score": 42, "note": "十字交乘法觀念需補救" }
  ]
}
```

```csv
date,period,class_id,seat_no,category,item,delta,severity,note
2026-09-15,2,801,5,discipline,遲到,-2,warning,"遲到10分鐘進教室"

2026-09-15,5,801,8,conflict,同儕衝突,-5,critical,"下課與09號發生推擠衝突"
```
