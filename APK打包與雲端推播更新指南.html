免重新安裝 APK • 連上 Wi-Fi 自動無感熱更新 • 100% 離線可用

💡 為什麼這個架構「連網就能自動推播更新」？

傳統原生 App 每次新增功能或改介面，使用者都要手動下載新的 .apk 並覆蓋安裝；
而本系統採用 Web + Service Worker 混合熱更新技術 (Live OTA)：

📶 連上網路時： App 啟動時自動在背景向雲端檢查 version.json，一旦發現新版程式碼，秒級自動下載並替換，手機畫面直接變成最新版，完全不用重裝 APK！
🟢 斷網離線時： 自動無縫切換到手機本機的高速快取與本地資料庫，教室沒網路照樣極速順暢記點！

🚀 三種最簡單的 APK 取得與發布方式：

🌟 方式一：PWABuilder 線上 30 秒 1 鍵生成 APK（最推薦、零技術門檻）

官方開源

微軟與 Google 共同維護的開源工具，只要貼上您的網址，即可在雲端一鍵生成可安裝的 Android APK 與 Google Play AAB 檔。

1 將本專案部署至免費的 GitHub Pages、Vercel 或您家中的 NAS Web 站點。
2 在瀏覽器打開 PWABuilder.com，貼上您的網址並點擊 Start。
3 點擊 Package for Android $\rightarrow$ 下載 .apk 檔直接安裝到手機！

☁️ 方式二：GitHub Actions 雲端自動打包工作流（完全全自動）

CI/CD

專案已為您內建 .github/workflows/build-apk.yml 工作流：

1 在電腦修改任何程式碼後，執行 git push 推送到 GitHub。
2 GitHub Actions 自動在雲端打包最新 APK，手機打開 App 瞬間自動連網熱更新！

💻 方式三：本機 Android Studio 原生專案源碼編譯

專案已在 android/ 目錄為您生成完整的 Gradle 原生專案，支援離線 WebView、雙向連線與手勢下拉刷新更新。

1 用 Android Studio 打開 d:\class_point_app_dev\android。
2 點選 Build $\rightarrow$ Build Bundle(s) / APK(s) $\rightarrow$ Build APK(s) 即可產出本機安裝檔！
🎉 系統已具備完整的 Live OTA 熱更新引擎與 APK 雲端編譯配置！
